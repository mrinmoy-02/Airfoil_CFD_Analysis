# Airfoil CFD Analysis – ANSYS Fluent

This project simulates airflow over an airfoil using ANSYS 2023 R2 Student Edition. It analyzes lift coefficient behavior, pressure distribution, and velocity contours.

## Objectives
- Validate aerodynamic behavior using ONERA M6 reference
- Study pressure and velocity fields
- Resolve numerical instabilities

## Tools Used
- ANSYS Fluent 2025 R2
- SpaceClaim for geometry prep
- Notion for progress tracking
